# 介面截圖

這裡保留全部檢查截圖（WebP 壓縮版），方便即時查看。**全部 110 張**存放在 GitHub 的 `screenshots` 分支：

    https://github.com/hinli2021/82hkg-scout-platform/tree/screenshots/docs/screens

截圖由 `tools/checks/` 內的檢查腳本在實機／離線試玩時自動拍攝；重拍之後可以再上載一次
（見 `docs/04-github.md`）。截圖由 PNG 轉成 WebP（同樣看得清，體積約為七分之一），兩者都不入版控，
所以 running 檢查不會弄髒 `git status`。
