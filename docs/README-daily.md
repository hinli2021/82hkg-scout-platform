# 每日挑戰 · Daily challenge

每天一款小遊戲，五分鐘內玩完，賺取積分。不需要任何設定，也不需要領袖批核。

## 玩法
- 棋盤由**香港日期**決定：全團當日玩同一個棋盤，時間可以互相比較。
- 四款遊戲輪流出現：水管接駁（轉動水管接通網絡）、數字滑塊（15 格滑塊）、
  掃雷（8×8，十個地雷）、記憶配對（八對童軍圖案）。
- 完成 **3 分**；**五分鐘內**完成 **5 分**。每天只計一次，重玩不計分。
- 積分經正常帳目（points_ledger）入帳，所以龍虎榜、餘額、紀錄都會自動更新。

## 給領袖
- 入口：童軍導覽「🎲 每日挑戰」，主頁亦有一張卡提示今日未玩。
- 紀錄：`設定 → 紀錄` 會見到 `daily_finish`；帳目內 `ref_id` 為 `daily:YYYY-MM-DD`。
- 沒有內容要維護：題目與棋盤由 `scout/daily.py` 即日生成，不會重複。
- 想換遊戲清單或分數，改 `scout/daily.py` 的 `ORDER`、`POINTS_DONE`、`POINTS_FAST`。

## 檢查
```
python3 tools/checks/check_daily.py http://127.0.0.1:5001
```
用 demo3（scout07）玩當日真實棋盤並領分；跑之前會先清走該帳戶的每日積分，
所以可以重複執行。`tests/test_daily_challenge.py` 則在四款棋盤上驗證公平性
（水管一定接得通、15 滑塊一定可解、掃雷十個不重複、記憶八對）、
不泄漏答案、以及「每日只派一次分、門票不可跨日或跨帳戶」。
